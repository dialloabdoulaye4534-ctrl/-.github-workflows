# WordCounter

Exercice 3 - Compteur de Mots (Java)

## Description
Programme Java qui lit un fichier texte et compte 
le nombre total de mots qu'il contient.

## Fonctionnement
- Lit le fichier texte ligne par ligne
- Sépare chaque ligne par les espaces
- Compte les mots de chaque ligne
- Affiche le total de tous les mots

## Comment exécuter
1. Ouvrir le projet dans IntelliJ IDEA
2. Placer un fichier texte nommé "texte.txt" 
   à la racine du projet
3. Exécuter la classe Main
4. Le nombre total de mots s'affiche dans la console

## Exemple de résultat
Total de mots : 43
